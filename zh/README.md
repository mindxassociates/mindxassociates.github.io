# Mind X Projects

A bilingual directory of free interactive tools and resources for clients,
therapists, clinicians, and other mental health professionals.

The English and Chinese pages automatically load public repositories owned by
`mindxassociates`. Repositories tagged `for-clients` appear under client tools;
repositories tagged `for-therapists` appear under therapist resources. Add or
remove these topics to control where a repository appears. No token, repository
secret, or GitHub Action is required.
